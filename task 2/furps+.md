| **Код** | **Требования**                         | **Комментарий**  |
|-----|------------------------------------|--------------|
| **F**   | **Функциональные (Functionality)**     |              |
| F1    | На сайте отображается список доступных депозитов с актуальными ставками                  |              |
| F2    | На сайте новый клиент может оставить заявку на депозит, оставив ФИО и телефон                  |              |
| F3    | Менеджеры call центра могут получать и просматривать новые заявки                                |              |
| F4    | В ИБ для клиентов банка отображается список доступных депозитов со ставками                  |              |
| F5    | При запуске ЗОДа (завершении опердня) в АБС специальные условия должны автоматически рассчитываться по всем клиентам                                  |  Здесь много подзадач - загнать логику экселей кредитного и депозитного отделов в АБС, вычисление ставок, передача ставок в ИБ            |
| F6    | В ИБ клиент банка может оставить заявку, выбрав депозит и сумму/валюту                                |              |
| F7    | Клиент подтверждает заявку в ИБ через СМС                                | Реализовывать через АБС (уже есть) или через шлюз нашими силами? Предварительно второе предпочтительнее             | 
| F8    | Сотрудник бэк офиса видит заявку на открытие депозита и может её подтвердить или отклонить                                |              |
| F9    | Клиенту отправляется СМС с условиями успешно открытого вклада                                |              |
| **U**   | **Удобство использования (Usability)** |              |
| U1    | Использовать цвета компании и брендированные элементы                                |              |
| **R**   | **Надёжность (Reliability)**           |              |
| R1    | Работа сервисов 24/7 с доступностью 99.9%                                |              |
| **P**   | **Производительность (Performance)**   |              |
| P1    | Отклик по всем операциям клиента - миллисекунды                                |              |
| P2    | Ускорить загрузку справочных данных в платежах                                |              |
| P3    | Развернуть "холодное" хранилище данных                                | Т.к. АБС горизонтально не масштабировать, выносим старые редко используемые данные в отдельное хранилище. Таким образом можем решить две проблемы - "Команда АБС утверждает, что база данных системы уже перегружена" и "при проведении платежей некоторые справочные данные загружаются больше секунды"             |
| **S**   | **Поддерживаемость (Supportability)**  |              |
| S1    | Внедрить процесс документирования разработки для дальнейшего развития системы                                |              |
| S2    | Подготовить команду к интеграционным и нагрузочным тестированиям                                | Ожидается большой приток новых клиентов при довольно больших архитектурных изменениях с нашей стороны             |
| **+R**  | **+ Ограничения (Restrictions)**       |              |
| +R1    | Обеспечить шифрование трафика при передаче данных с сайта и ИБ                                |              |
| +R2    | Использовать существующие технологии по максимуму - Oracle, MS SQL. Технологии только те, в которых есть экспертиза. Для очереди использовать Kafka                                 |              |
| +R3    | Переход на микросервисную архитектуру, только создание депозита                                | 1. Только если хватит ресурсов 2. АБС довольно неповоротливая система, может потребоваться дублирование создания депозита и в микросервисе, и в АБС |
| +R4    | "Изучив заявку в системе кол-центра, менеджер может предложить особые условия"                                | Уточнить у бизнеса, может потребоваться доп интеграция с АБС (сейчас есть только в одну сторону, передача заявок в АБС). Если особые условия складываются из общих маркетинговых акций, то доработка не нужна. Если будет анализ клиента - нужны доработки             |
| +R5    | Настроить доступы в АБС, что отделы кредитов и депозитов не видели данных друг друга                                | Выполнить требования ИнфоБеза в АБС, из-за которых изначально появились разные эксельки и длиннющий процесс согласования ставок. Важно - может потребоваться не только настройка доступа, а отдельный функционал - разные представления, разделение выполняемых процедур в АБС, в т.ч. переработка вендорских. То есть заложить больше времени             |
| +R6    | Реализовать прослойку между ИБ и АБС                                | Для балансировки нагрузки, т.к. АБС уже перегружена. Вынести те же ставки в БД ИБ, которые раз в день будут обновляться            |
